# 🦀CDCG Dashboard
This React-based administrative platform was engineered to modernize and centralize data entry operations for CDCG LLC. By leveraging a custom-built interface, the application replaces fragmented workflows with a high-efficiency digital pipeline, ensuring data integrity from the point of capture to long-term storage.

## 📦Technologies
- `React`
- `Typescript`
- `Next.js`
- `ShadCN UI`
- `TailwindCSS`
- `Vercel`

## 📋Features
Here is a non-exhaustive list of what you can do with the CDCG Dashboard
- **Metrics at a Glance:** The main home page houses multipe widgets such as local weather, estimated clock-in time, and much more
- **Business Form Hub:** Looking for a form? All of the forms are consolidated down into one searchable hub! Find any data entry form in seconds!
